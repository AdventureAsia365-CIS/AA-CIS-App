## Decisions

- Scoped "UI text" (Phần 1) to visible text only — labels, tooltips, placeholders, error
  messages, confirm dialogs. Left engineering-log comments untouched (many contain Vietnamese
  in dated AA-XXX changelog entries, e.g. `SlateTab.tsx`'s own file header) — those are
  historical dev notes, not something a tenant ever sees, and out of this issue's stated scope.
  One exception: a present-tense comment on `SlateTab.tsx`'s `pick()` error handler directly
  quoted the OLD Vietnamese button label ("Chọn viết") to describe CURRENT behavior — updated
  that one quote to the new English label ("Pick to write") since it now described a
  non-existent string, not because it's UI text.
- Diacritic-only sweep (`grep -rnP '[àáâãèéêìíòóôõùúýăđĩũơưẠ-ỹ]'`) for STEP0 detection. Reliable
  here because this codebase's Vietnamese always carries diacritics — no evidence of a
  diacritic-free Vietnamese string anywhere in a repo-wide check of the tenant portal tree.
