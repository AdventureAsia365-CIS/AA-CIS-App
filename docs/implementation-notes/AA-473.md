# AA-473 — Xoá Gate A hoàn toàn + dọn 11 tenant test

## Decisions
- Xoá hẳn Gate A (không chỉ deprecate) — cùng dạng đã làm với Gate B ở AA-472. Tenant giờ
  `is_active=true` ngay khi `create_tenant()` INSERT.
- `acp_shared.tenant_onboarding` DROP TABLE hẳn (không chỉ xoá cột) — STEP0 xác nhận không còn
  caller production nào khác ngoài `admin.py` (grep sạch `services/acp_planning/*.py` và toàn
  repo).
- `list_tenants()`'s `pending_tenants[]` bỏ hẳn, không thay bằng view "tenant đã tắt" nào khác —
  đơn giản nhất, đúng tinh thần ADR-2026-038 §0.2. Nếu Nghiệp muốn xem tenant `is_active=false`
  sau này (soft-delete/offboard), đó là tính năng riêng ngoài scope AA-473.
- Planning tab admin (Nhánh 3 STEP0) KHÔNG động tới trong PR này — STEP0 xác nhận T7 không có
  đường ghi markets/channels nào, admin Planning tab là nguồn ghi DUY NHẤT. Tách sang AA-474
  (Backlog).
- Data cleanup (11 tenant test) gộp chung task/PR narrative với xoá code Gate A theo yêu cầu
  Nghiệp, nhưng DELETE thật là thao tác DB riêng (không nằm trong git diff) — có DRY RUN riêng,
  chờ xác nhận trước khi chạy DELETE.

## Changed
- `api/routers/admin.py`: xoá `approve_gate_a()`/`get_gate_a_status()`/`GateAApproveRequest`;
  `create_tenant()` INSERT `is_active=true` thẳng, xoá insert `tenant_onboarding`; `update_tenant()`
  PATCH bỏ nhánh check `approval_status=='approved'` khi activate; `list_tenants()` bỏ
  `pending_rows`/`pending_tenants`/`pending_total` khỏi response.
- `frontend/app/admin/tenants/page.tsx`: xoá `OnboardingTabContent`, `GateAStatus`, `StepHeader`
  (chỉ dùng bởi Onboarding tab), `getCookie()` (chỉ dùng bởi Onboarding tab), `PendingOnboarding`/
  `PendingTenant` types, `pendingStepLabel()`, `PendingTenantCard`, `PendingOnboardingSection`,
  `pendingTenants` state; bỏ `"onboarding"` khỏi `DTab` union + `TABS` list; `TenantDetail` bỏ
  prop `isActive`/`onGateAApproved` (không còn cần chọn tab mặc định theo trạng thái); default
  tab luôn `"tours"`.
- `api/migrations/120_drop_gate_a.sql`: `DROP TABLE acp_shared.tenant_onboarding` (chưa apply).
- `tests/unit/test_aa309_tenant_onboarding.py`: xoá `TestCreateTenantIsInactive`/`TestGateAApprove`/
  `TestGateAStatus`/`TestListTenantsPending`/`TestUpdateTenantGateAGuard`; thêm
  `TestCreateTenantIsActive` (xác nhận hành vi mới `is_active=true`); giữ nguyên
  `TestCreateTenantPostsPerWeek`.
- `tests/verify_scripts/aa389_gate_a_bypass_verify.py`: xoá cả file (verify script riêng cho cơ
  chế Gate A guard, không còn đối tượng để verify).
- Verify local: `pytest tests/unit/` 1560 passed; `flake8 api/routers/admin.py
  tests/unit/test_aa309_tenant_onboarding.py` sạch (3 cảnh báo B017 pre-existing, không do PR này
  gây ra — xác nhận bằng `git show main:...` cùng lỗi); `next build` (frontend) compile sạch,
  `/admin/tenants` vẫn nằm trong route list, không lỗi TypeScript.

## Tradeoffs
- Xoá `pending_tenants[]` hoàn toàn thay vì giữ lại field rỗng để tương thích ngược — không có
  consumer nào khác ngoài chính component vừa xoá (`PendingOnboardingSection`), nên giữ lại field
  chết không có lý do.
