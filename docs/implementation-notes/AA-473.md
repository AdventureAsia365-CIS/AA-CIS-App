# AA-473 — Xoá Gate A hoàn toàn + dọn 11 tenant test

## Decisions
- Xoá hẳn Gate A (không chỉ deprecate) — cùng dạng đã làm với Gate B ở AA-472. Tenant giờ
  `is_active=true` ngay khi `create_tenant()` INSERT.
- `acp_shared.tenant_onboarding` DROP TABLE hẳn (không chỉ xoá cột) — STEP0 xác nhận không còn
  caller production nào khác ngoài `admin.py` (grep sạch `services/acp_planning/*.py` và toàn
  repo).
- `list_tenants()`'s `pending_tenants[]` bỏ hẳn, không thay bằng view "tenant đã tắt" nào khác —
  đơn giản nhất, đúng tinh thần ADR-2026-038 §0.2. Nếu Nghiệp muốn xem tenant `is_active=false`
  sau này (soft-delete/offboard), đó là tính năng riêng ngoài scope AA-473.
- Planning tab admin (Nhánh 3 STEP0) KHÔNG động tới trong PR này — STEP0 xác nhận T7 không có
  đường ghi markets/channels nào, admin Planning tab là nguồn ghi DUY NHẤT. Tách sang AA-474
  (Backlog).
- Data cleanup (11 tenant test) gộp chung task/PR narrative với xoá code Gate A theo yêu cầu
  Nghiệp, nhưng DELETE thật là thao tác DB riêng (không nằm trong git diff) — có DRY RUN riêng,
  chờ xác nhận trước khi chạy DELETE.
