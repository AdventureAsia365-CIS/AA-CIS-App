## Decisions

- **Flagged Score and Route/Hub, not just Segment.** The issue's title and body name all four

  but Score/Route/Hub's own glossary entries and the ownership table rows for them (#5, #6) still

  ADR-0001 stays a historical record (why the debt exists — AA-509 predates AA-526, the AA-526

  Also added a short "Decision" section directly inside ADR-0001 (the issue asked for the decision
  line there too, not only in a new ADR) that points to ADR-0003 for the full record — so a reader
  who only opens 0001 still sees the decision, not just the history.

  different question (what's shared today) and stays accurate as a fact statement. What changed is

## Tradeoffs

- **Warning placement**: considered putting the warning only inside the Segment/Score/Route/Hub
  glossary entries (more locally scoped, less visually loud) vs. a standalone banner at the top of
  the whole file (louder, but the file covers other subsystems too where it's irrelevant noise).
  Chose the top-of-file banner because the issue's own stated goal is "Claude Code tự thấy cảnh
  báo này mỗi lần đọc CONTEXT.md" — a reader skimming the file top-to-bottom before starting any
  task sees it before reaching the specific term, which a locally-scoped note can't guarantee.
- **One shared warning vs. four separate ones**: Segment/Score/Route/Hub all point back to the
  same principle and the same ADR-0003, rather than each getting an independently-argued
  tech-debt case. They share one root cause (Segment was speced pre-Atom-platform-wide; Score/
  Route/Hub are all downstream of Segment) — writing four independent justifications would
  overstate how separable the decisions actually are.
- **ADR-0001 vs ADR-0003 split**: could have just rewritten ADR-0001 in place with both the
  history and the forward decision. Split per the issue's explicit ask, and because it keeps
  ADR-0001 answerable to "why does this exist" without needing a future reader to also parse
  "what are we going to do about it" in the same document — matches this repo's ADR-0002
  precedent (Search Demand) of one ADR per one decision.
