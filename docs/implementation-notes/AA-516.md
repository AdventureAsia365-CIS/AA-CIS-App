## Tradeoffs

- Left 3 additional genuinely-dead functions in place (`fetch_atoms_by_trip`, `fetch_due_slots`,
  `mark_slot_status`) rather than expanding this cleanup's scope beyond what was explicitly
  confirmed — a smaller, ready-to-approve follow-up is lower risk than silently deleting
  functions Nghiệp didn't review and name, even when the STEP0 work to justify it is already
  done here.
- Historical docs (`docs/implementation-notes/AA-301.md`, `AA-377.md`, etc.) still reference the
  now-deleted functions by name — left untouched. This repo's convention treats
  `docs/implementation-notes/*.md` as append-only historical record, not living documentation;
  retroactively editing a past issue's own notes to match code that has since evolved would
  misrepresent what that issue actually built/verified at the time.
- Some in-code comments elsewhere (e.g. `services/acp_angle_gate/service.py`,
  `services/acp_planning/lock_status.py`, `services/acp_produce/slot_runner.py`,
  `services/acp_planning/tenant_config.py`) mention the deleted functions by name as
  "deliberately NOT called" contrast text — left as-is, since they remain factually accurate
  (that code still deliberately does NOT call these functions; the functions merely no longer
  exist to call, which strengthens rather than invalidates the point being made).
