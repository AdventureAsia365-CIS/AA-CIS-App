## Tradeoffs

- Considered leaving `ACP_V1_NAV` in place (commented out or unused) in case the entry
  needs restoring later — rejected: the array is 6 lines in git history, trivially
  restorable via `git show`/revert, and an unused-but-present array would trip
  `no-unused-vars` lint noise for no benefit. "Restorable" is satisfied by git history,
  not by dead code left in the file.
